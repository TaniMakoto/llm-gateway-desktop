This is a pinned reference catalog, not a live probe or a guarantee that a
third-party provider implements every advertised capability. Provider model
declarations take precedence. Unknown models remain unknown. Updates must be
reviewed and pinned explicitly; the gateway does not fetch this catalog at runtime.
