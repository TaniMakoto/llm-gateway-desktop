# 思考请求处理

每次候选上游请求分别处理思考参数。入口请求保持不变；协议转换、模型映射和请求体覆盖之后，再根据最终模型校验，随后记录实际发送值。

能力来源按当前路由的模型能力声明、本项目模型目录、固定版本 CPA 模型目录依次补充。供应商 `/models` 明确返回的等级枚举优先于通用目录；没有返回等级或空列表表示未知。目录是参考数据，不代表实测支持或上游实际执行程度。

处理规则：

- 同协议族中，已知列表不支持的等级在本地返回 400，错误包含模型、请求等级和支持列表；不会把本地拒绝计为上游失败尝试。
- 跨协议或模型族转换时，保留原始客户端意图，映射到目标支持的等级。`xhigh` 优先尝试 `xhigh/max/high`，`max` 优先尝试 `max/xhigh/high`；其他等级选择最接近值，距离相同优先较低值。
- 等级和预算转换使用估算值；预算受目录范围约束，Anthropic 还受 `max_tokens - 1` 限制。原生显式预算超限直接拒绝。
- 能力未知时保留请求，日志注明未验证。不会仅凭目录缺少字段就删除思考参数。
- DeepSeek、OpenRouter 等协议配置保留其字段位置和转换规则；不支持 effort 的配置不会被重新注入 effort。转换结果仍按已知模型等级校验。
- `disabled` 删除思考控制参数；`force` 不绕过最终能力校验。Responses 的 summary 配置单独保留。

请求日志的尝试明细展示“思考处理”说明，包括能力声明来源、映射或本地拒绝原因。客户端请求、最终发送、上游明确返回的参数继续分别展示；上游未返回时不推测有效等级。

CPA 数据版本、原始地址与许可见 `src-tauri/src/resources/cpa/README.md`。目录不会在运行时自动更新。
